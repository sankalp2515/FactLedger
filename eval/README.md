# Evidence evaluation protocol

The ten `use-cases.jsonl` rows are synthetic semantic regression prompts. They do not constitute independent evaluation, real public-project findings, or 100 adjudicated pairs. UC-10 additionally requires the application revision/export immutability test; a relation score alone cannot validate that workflow.

1. Recruit two qualified reviewers who did not implement the model and disclose their expertise/conflicts. Assemble at least 100 stratified real evidence pairs across the ten use cases, including decisive positives, contrary records, unavailable sources, attribution traps, missing dates, unit/period mismatches and repeated reporting.
2. Freeze source bytes/extraction hashes and claim scope. Each reviewer independently assigns one of SUPPORTS, CONTRADICTS, CONTEXT, INCOMPARABLE, INSUFFICIENT, exact quote/anchor, scope comparison and rationale while blind to predictions. Adjudicate disagreements with a third reviewer. Preserve initial labels and disagreement rate. Only these rows use `label_origin: independent-adjudicated`.
3. Freeze dataset before running a pinned model/configuration. Hold out evaluation records from prompt development; report source/project families across splits to avoid near-duplicate leakage. Persist provider/model, timestamp, budgets, search/query trail and latency/cost including failed attempts. Do not include secrets or personal beneficiary information.
4. Join actual predictions to rows by unique id (missing predictions are errors). Run `python eval/score.py predictions.jsonl`. Precision = correct decisive predictions / all decisive predictions. Coverage = decisive predictions / all pairs. Abstention = INSUFFICIENT / all pairs. Context and incomparable predictions are reported separately from abstention through exact relation accuracy. No decisive predictions yields null precision, never 100%.
5. Report relation confusion matrix, per-use-case counts, 95% binomial uncertainty interval for decisive precision, coverage/abstention, measured accepted-case latency and costs. Target >=90% decisive precision is an engineering release hypothesis, not achieved quality. Compare baseline using the identical records and scope. Do not select only successful runs.

No synthetic result establishes newsroom usefulness, time savings or expert validation. Runtime fixture mode must remain visible in the UI and exported packs. Real-world accuracy claims require independent adjudication.
