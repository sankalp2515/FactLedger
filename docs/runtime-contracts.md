# Runtime interfaces for implementation

Root owns `apps/api/product_core/{config,db,models,schemas,service,auth,main}.py` and API/domain tests. Investigation workstream owns `investigation/`, `domain/`, `worker.py` and their tests. Frontend owns `apps/web/`. Operations owns `infra/`, `scripts/`, `eval/`, CI, migrations and runbooks.

`config.Settings`: database_url (SQLite local default, PostgreSQL Compose), artifact_dir, mode development/production, session_secret, serpapi_api_key, groq_api_key, nvidia_api_key, llm_provider groq/nvidia, llm_model, provider base URL derived from enum, max_run_seconds=600. Environment loaded from root .env with extra=ignore; keys never serialized.

`db.Base`, `db.engine`, `db.SessionLocal`: SQLAlchemy 2. Tables use UUID strings (36) and workspace_id/case_id foreign keys. `db.init_db()` creates tables for local use; Alembic migrations for deployment. UTC datetimes are strings/DateTime consistently handled in services.

`models.Case`: id, workspace_id, title, original_claim, revision int, state, tags JSON, assignee_id nullable, archived bool, deleted_at datetime nullable, created_at/updated_at.
`models.Revision`: id, workspace_id, case_id, number, payload JSON, created_at. Payload `{claims:[],projects:[],evidence:[],sources:[],ledger:{stages:[],funding:[],metrics:[],derived:[],gaps:[]},notes:[],conclusion:"",lineage:[]}` immutable.
`models.Run`: id, workspace_id, case_id, base_revision int, state, mode live/fixture, plan JSON, budget JSON, usage JSON, results JSON, checkpoint JSON, error nullable, lease_owner nullable, lease_generation int, lease_expires_at datetime nullable, created_at/updated_at. `results` follows revision payload shape; progressive results do not mutate case head. `checkpoint` stores action outcomes/cursors. `budget` keys searches/documents/rounds/tokens/seconds/usd (defaults 12/30/3/60000/600/2); `usage` same keys plus cost_estimated bool.
`models.RunEvent`: id, workspace_id, case_id, run_id, seq, type, payload JSON, created_at. Unique run seq; insert while Run row locked. `models.Source`: id, workspace_id, case_id, run_id nullable, url, title, status, content_hash, extraction_hash, artifact_path, text_path, metadata_json JSON. Records immutable. Metadata includes extraction_version, date provenance, total/extracted pages, source_type.
`models.Evidence`: id, workspace_id, case_id, run_id, claim_id, source_id, relation, quote, anchor JSON, comparison JSON, rationale, metadata_json JSON. Immutable; human overrides in Revision payload.

`investigation.executor.execute_run(run_id: str) -> None`: sync worker entry, uses SessionLocal and Settings. It owns row-fenced execution, provider reservations, checkpoints/events, pause/cancel handling; updates Run.results only. API `/runs/{id}/integrate` calls service to create new revision with expected_revision and compatible scope.
`investigation.acquisition.acquire(url: str, page_ranges: list[list[int]] | None = None) -> AcquiredDocument`: API manual additions can use same bounded acquisition adapter. Fields title,text,raw bytes,media_type,metadata dict; persist via artifact helper.
`domain.evidence.analyze(claim:dict, document:dict) -> list[dict]` optional model adapter; deterministic validator must enforce quotes and scope. `investigation.storage.store_document(workspace_id,case_id,document) -> dict` owns immutable raw/text files and metadata, no user-derived paths.

API session: GET `/v1/session` -> `{user:{id,name},workspace:{id,name},role,csrf_token,mode,providers:{serpapi:bool,groq:bool,nvidia:bool}}`; POST `/v1/auth/dev` `{user_id:researcher|editor|owner}` sets local cookie; mutations require X-CSRF-Token from session. Root serves static built web on port 8000; Vite proxies /v1.

Case list GET `/v1/cases?search=&state=&archived=false&cursor=&limit=25` -> `{items:[case],next_cursor}`. POST case `{title,original_claim}` -> case detail. Case detail GET `/v1/cases/{id}?revision=` -> `{...case,payload,latest_run:run|null,review_requests:[]}`. POST scope `{expected_revision,claims:[{id?,text,subject,geography,period,stage,measure,value?,unit?,denominator?,attribution?}]}`. POST plans `{expected_revision}` -> `{id,scope_hash,queries:[],budget}`. POST runs `{expected_revision,plan_id,mode:live|fixture,budget?}` with Idempotency-Key -> run. GET run -> run (includes results,events); SSE `/runs/{id}/events`. POST run pause/resume/cancel; POST integrate `{expected_revision}` -> case detail.

Manual additions POST `/cases/{id}/sources` JSON `{expected_revision,url,page_ranges?}`; POST `/cases/{id}/uploads` multipart PDF + expected_revision; each returns updated case detail after bounded acquisition. GET `/sources/{id}` -> source+text; GET `/sources/{id}/download` authenticated raw artifact. Overrides PATCH `/evidence/{id}/relation` `{expected_revision,relation,reason}`; POST `/cases/{id}/ledger-overrides` `{expected_revision,observation_id,corrected_fields,reason}`. Notes POST `{expected_revision,text,attribution,evidence_ids?}`. PATCH case metadata; DELETE case with expected_revision query; POST restore. GET revision history/diff.

POST review requests `{expected_revision,conclusion,citations:[]}`; GET `/review-requests` queue `{items:[]}`; GET request -> frozen case payload/request. POST `/review-requests/{id}/decisions` `{decision:APPROVE|RETURN,reason,expected_revision}` with idempotency. POST exports `{revision,format:md|html|json}` returns `{id,download_url}`; GET `/exports/{id}/download`. GET members; POST/PATCH membership owner only.

Evidence shape `{id,claim_id,source_id,relation,quote,anchor:{start,end,page?},comparison:{...},rationale,metadata:{...}}`. Source shape `{id,url,title,status,text?,metadata:{...}}`. Ledger stage `{id,claim_id,source_id,stage,event_date,quote,evidence_ids}`; funding/metric analogous with kind/value/unit/period/denominator. Gaps `{claim_id,type,reason,next_evidence_needed}`. The reader should show original source text and highlight anchors, never render external HTML.

No hardcoded production/demo outcomes. Fixture mode is explicitly labeled and uses synthetic public-project examples. Live mode must use configured search/model providers and fetched sources. Never expose keys or inspect .env content in tool output.
